ARSE Inventory Management System is a desktop application I built using Python and the Tkinter library for the user interface. I developed the project in Visual Studio Code and managed the database with Microsoft SQL Server Management Studio.

The system lets users manage inventory by recording products, tracking stock levels, handling stock-in and stock-out, and keeping records up to date. It also includes user authentication, product and supplier management, and generates reports for daily business needs.

The application uses Python and Microsoft SQL Server to store data reliably, quickly retrieve inventory details, and automatically update stock levels after each transaction. Its Tkinter interface is easy to use, which helps prevent mistakes and makes operations run more smoothly.

This project shows skill in Python programming, building GUIs with Tkinter, designing and managing SQL databases with Microsoft SQL Server Management Studio, connecting to databases, handling CRUD operations, setting up user authentication, and creating useful business applications in Visual Studio Code.
